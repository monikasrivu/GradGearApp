# 🚀 GradGear - Roadmap

Here are a few ideas to improve the project further:

1. **Dark Mode Support** 🌙  
   Add a theme toggle to switch between light and dark modes for better user experience.

2. **Export to PDF / Resume Builder** 📄  
   Allow students to export their portfolio as a PDF resume using customizable templates.

3. **Admin Notifications Panel** 🔔  
   Show alerts to admins for new student entries, updates, or flagged data.

4. **AI-based Skill Suggestions** 🤖  
   Suggest skills or projects based on the student’s existing profile using AI models.

5. **Chat Assistant for Guidance** 💬  
   Add a small chatbot or FAQ section to guide students while filling out their profile.
